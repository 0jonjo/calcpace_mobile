# Plan

The goal isn't a super app. It's a small app that someone opens and thinks "nice app". It is also a portfolio piece. Every milestone ends with something shipped: a store release, a production deploy, and a short write-up.

## Phase 1: parity with the TWA (Android 2.0.0)

Replace the Trusted Web Activity without anyone losing anything.

- [x] Hotwire Native shell (1.3.1), single navigator, the site draws its own header and tab bar
- [x] Same `applicationId` (`app.calcpace.twa`), same icon, `versionCode` 3
- [x] calcpace.app App Links open in the app (assetlinks already serve the package)
- [x] External links open in a Custom Tab; `mailto:`/`tel:` go to the system
- [x] Edge-to-edge: the page stays clear of the status bar, gesture bar and keyboard
- [x] Google/Strava sign-in through a Custom Tab with a PKCE-bound one-time ticket (app side)
- [ ] Rails side: client-side app detection, `/configurations/android_v1.json`, `/app_auth/*` handoff, no Play banner or ads in the app (calcpace_web PR)
- [ ] Smoke test on an emulator and on a real phone: browse, sign in by email, Google and Strava, sign out, open a shared link
- [ ] Signed release build → Play internal testing → closed testing → production (after the TWA's production review is settled)

Known gaps in phase 1:

- Connecting Strava to an existing account can't run inside the WebView yet; the app tells you to do it on the website.
- minSdk goes from 21 (TWA) to 28. Older phones keep the TWA build that is already installed.

## Phase 2: the native touches (Android 2.x)

Ordered by impact for effort.

1. **"Your run is in" notification:** a one-line summary when a Strava (later Health Connect) run arrives. Needs FCM plus a Rails endpoint to register device tokens.
2. **Share card:** an image of the run (map and key numbers) for Instagram stories, generated by Rails and shared through a bridge component and the Android share sheet.
3. **Health Connect import:** runs from Garmin, Samsung, Pixel Watch and others without Strava, which caps the API at 10 athletes.
4. **Home screen widget:** the week's distance and runs, and the next race.
5. Native bottom tabs and toolbar, with the web versions hidden in the app.

## Phase 3: later

- iOS (`ios/`, Hotwire Native iOS, HealthKit)
- Native GPS run recording (foreground location service, live pace, km voice cues)
- Offline: service-worker cache through Turbo's offline support when it ships; the calculator's math on the device (Opal or a JS port tested against vectors generated by the calcpace gem)
- Monetization: ads for free users and a subscription that removes them, only once there is a user base
